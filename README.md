# 🚗 DriveEase – Vehicle Rental Website

A web-based vehicle rental platform designed to make vehicle discovery and rental browsing simple, convenient, and user-friendly.

## 🌐 Live Demo

[Visit DriveEase](https://shanisbasheer.github.io/drivease-vehicle-rental/)

## 📌 Project Overview

DriveEase is a vehicle rental website developed to provide users with a simple platform to explore available vehicles and learn about rental options.

The project focuses on creating a clean user interface, easy navigation, and a smooth browsing experience.

## ✨ Features

- User-friendly website interface
- Vehicle browsing and exploration
- Responsive website layout
- Easy navigation between website sections
- Vehicle rental-focused design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
